# Release checklist

- [ ] Authors approve code and data licensing; replace rights-reserved notice only with authorisation.
- [ ] Authors review the hazard-cache and mutation-catalogue discrepancies in the scientific audit.
- [ ] Confirm manuscript/preprint status and add real DOI/URL when available.
- [ ] Review complete-grid validation and figure captions.
- [ ] Choose an authorised GitHub remote and publish without exposing unrelated workspace data.
- [ ] Add remote-specific CI badge after a real workflow run.

This repository does not itself establish manuscript acceptance, preprint deposition, or public-release permission.
