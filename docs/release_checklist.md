# Release checklist

## Completed local preparation

- [x] Clean `main` branch with scientific source, configurations, lockfile, tests, CI, citation, numerical data, and figures tracked.
- [x] Reachable commit-history and tracked-file privacy/security audit; no credential findings requiring history rewriting.
- [x] No unrelated research files, rejected-size files, virtual environments, or temporary checkpoints tracked.
- [x] README links, badge URLs, banner rendering, figure exports, and CFF metadata checked.
- [x] Quick tests, fresh smoke test, installation, cached reproduction, and complete-output regression checked.
- [x] Manual GitHub creation instructions, About text, and topics prepared in [publishing.md](publishing.md).
- [x] No push, repository creation, authentication, upload, visibility change, or remote modification performed.

## Author decisions and actions

- [ ] Approve code/data licensing; replace the existing notice only with authorised terms.
- [ ] Review the inherited implementation/Methods discrepancies in the [scientific audit](../reports/scientific_fidelity.md).
- [ ] Add real manuscript/preprint identifiers when available; none are required or fabricated for this preparation.
- [ ] Create the empty GitHub repository and push `main` yourself.
- [ ] Verify the first GitHub Actions run; add an accurate repository-specific badge if desired.

Local publication preparation does not establish manuscript acceptance, preprint deposition, or permission to relicense co-author-owned material.
